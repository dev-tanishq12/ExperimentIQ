## Quick Start
```python
from quality_profiler import DataQualityProfiler

profiler = DataQualityProfiler()
df = profiler.load_data('experiment.csv')
report = profiler.profile_data()
profiler.save_report(report, 'quality_report.json')
```

## Report Structure (What Member 2 Gets)
```json
{
  "file_info": {"rows": 10000, "columns": 10},
  "column_profiles": {...},
  "issues": [
    {
      "column": "conversion",
      "type": "missing_values",
      "severity": "high",
      "count": 850,
      "suggestion": "Impute or drop rows"
    }
  ],
  "summary": {"total_issues": 12, "critical": 2, "high": 3},
  "quality_score": 0.72
}
```

## Severity Levels
- 🔴 **CRITICAL**: Experiment invalid. STOP.
- 🟡 **HIGH**: Must fix
- 🟠 **MEDIUM**: Should investigate
- 🟢 **LOW**: Minor cleanup

## What Member 2 Should Do With My Report

| Issue Type | Action |
|------------|--------|
| `missing_values` | Impute (mean/median/mode) or drop |
| `duplicate_rows` | Drop duplicates |
| `duplicate_users_across_groups` | **CRITICAL**: Fix design or stop |
| `invalid_values` | Replace with valid values |
| `outliers` | Cap/winsorize or investigate |
| `inconsistent_date_formats` | Standardize format |
| `case_inconsistency` | Convert to lowercase |
| `whitespace_issues` | Strip whitespace |
| `mixed_types` | Extract numeric values |
| `empty_column` | Drop column |
